# Casa3D para iPad

Esta versión está preparada como PWA (Progressive Web App).
En iPad, para instalarla como aplicación:
1. Debe abrirse desde una dirección HTTPS en Safari.
2. Pulsa Compartir.
3. Pulsa "Añadir a pantalla de inicio".
4. Ábrela desde el icono Casa3D.

IMPORTANTE: un ZIP no puede instalarse directamente como app en iPad. Para instalarla con un icono y modo pantalla completa hace falta publicar estos archivos en una URL HTTPS.

La app guarda el proyecto localmente en el navegador.
